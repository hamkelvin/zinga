# Zinga 5G Landing Page — Creative Prototype

Responsive HTML/CSS/JavaScript landing page based on the supplied Zinga 5G creative brief.

## Creative direction
Master idea: STAY IN THE FLOW
Core proposition: Zinga 5G keeps up with the way you live.

Includes: hero, 5G benefits, Why Zinga, lifestyle section, Smarter Way to Live, 3GB/₦1,500 offer, 200 bonus minutes, reliability/coverage, conversion CTA, mobile navigation, scroll reveal and CTA demo interaction.

## Run
Extract the ZIP and open `index.html`. No build tools are required.
